# market-prices — เทียบราคาตลาด + แนะนำราคารับซื้อ

เป้าหมาย: บอกว่าราคารับซื้อของ khaiphone **แข่งได้ไหม** เทียบคู่แข่งจริง (เน้นคู่แข่งที่ยิงแอด = สนามจริง) แล้วแนะนำรุ่นที่ควรปรับ
**ไม่แก้ราคาให้เอง** — เจ้าของตัดสินใจปรับใน `/admin/price-settings` (จะให้ร่างค่าที่แนะนำก็ได้)

## Input
- รุ่นที่ต้องการ เช่น `/market-prices iPhone 15 Pro Max` · เว้นว่าง = เช็กรุ่นฮิตหลายรุ่น

## ขั้นตอน

### 1. ราคาของเราก่อน
```bash
node scripts/khaiphone-price.mjs "iPhone 15 Pro Max"   # เว้นว่าง = ทุกรุ่น
```
ได้ `price_good` (ราคาอ้างอิงต่อรุ่น) + ราคาต่อความจุ — นี่คือฐานที่จะเทียบ

### 2. อ่าน registry คู่แข่ง
เปิด `content/competitors.md` → ได้รายชื่อคู่แข่ง + ประเภทการดึง (auto / screenshot / ad-only)
**เน้นกลุ่ม "คู่แข่งที่ยิงแอด" เป็นหลัก** (สนามจริง) ไม่ใช่แค่เว็บ SEO

### 3. เก็บราคาคู่แข่ง (ผสม 3 ทาง)
- **auto (เว็บมีตาราง):** WebFetch หน้าราคาของคู่แข่ง (เช่น bkkapple.com/iphone/iphone-15-pro-max) → ดึงราคา**รับซื้อ**ของรุ่น/ความจุ/เกรดที่ตรงกัน
- **screenshot / ad competitors (yellobe, เพจ FB, LINE):** ราคา**ดึงอัตโนมัติไม่ได้** (ฟอร์มไดนามิก/รูปแอด) →
  **ขอให้ผู้ใช้แปะ screenshot** ราคาคู่แข่ง (จากแอด FB / โพสต์ / LINE / หรือรันฟอร์มคู่แข่งแล้วแคป) → **อ่านตัวเลขจากรูป**มาใช้
- **Facebook Ad Library:** ถ้าอยากรู้ว่าใครยิงแอดอยู่ตอนนี้ → ค้น `facebook.com/ads/library` ด้วยคีย์เวิร์ด "รับซื้อ iphone" ประเทศไทย (ระบุตัวคู่แข่งได้ แม้ราคาจะอยู่ในรูป → ขอ screenshot ต่อ)
- **แยก "รับซื้อ" ออกจาก "ขายปลีก/มือสอง"** เสมอ (ขายปลีกสูงกว่า ใช้ดูเพดานเท่านั้น)

### 4. สรุป + เทียบ
- รวมราคา**รับซื้อ**ของคู่แข่งต่อรุ่น → ต่ำสุด / กลาง / สูงสุด
- เทียบกับ `price_good` ของเรา:
  - 🔴 **เราต่ำกว่ากลางตลาดมาก** → เสี่ยงลูกค้าไปหาคู่แข่งที่ให้มากกว่า → แนะนำขึ้น
  - 🟡 **เราสูงกว่าตลาด** → เสี่ยง margin/รับแพงไป → แนะนำระวัง/ลด
  - 🟢 อยู่ในช่วงแข่งได้

### 5. Output
ตารางต่อรุ่น: `รุ่น | ราคาเรา | คู่แข่ง(ต่ำ–กลาง–สูง) | ส่วนต่าง | คำแนะนำ` + แหล่งอ้างอิง/ที่มา screenshot
สรุปสั้นๆ ว่ารุ่นไหนควรปรับด่วนสุด · ถ้าผู้ใช้อยากได้ ค่อยร่างราคาที่ควรตั้ง (แต่ไม่บันทึกให้เอง)

## ข้อควรระวัง (พูดตามตรง)
- ราคาคู่แข่ง**เปลี่ยนรายวัน** + ขึ้นกับเกรด/สภาพ/โปรโมชัน → ใช้เป็น**ทิศทาง** ไม่ใช่ตัวเลขตายตัว
- อย่าแนะนำให้ขึ้นราคาสูงกว่าตลาดเพื่อแย่งลูกค้าโดยไม่ดู **margin** (รับแพง = กำไรหด) — สมดุลระหว่างแข่งได้กับกำไร
- คู่แข่งบางเจ้าโชว์ราคา "สูงสุด/เกรด A เป๊ะ" เพื่อล่อ แต่กดหน้างาน → ระบุว่าเป็นราคาโฆษณา ไม่ใช่ราคาจริงเสมอไป
- ราคา Facebook/LINE ดึงอัตโนมัติไม่ได้ → ถ้าผู้ใช้ไม่แปะ screenshot ให้ระบุว่า "ไม่มีข้อมูลคู่แข่งกลุ่มนี้" อย่าเดา
